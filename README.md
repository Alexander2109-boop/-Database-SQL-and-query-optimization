# 🗄️ Database SQL & Query Optimization

## 📝 Descripción
Este proyecto se enfoca en el diseño, normalización y optimización de una base de datos relacional para la gestión de competencias de eSports. El objetivo principal fue reducir los tiempos de respuesta y asegurar la integridad de los datos mediante técnicas avanzadas de SQL.

---

## 🚀 Puntos Clave del Proyecto
Basado en el informe de optimización y modelado, se implementaron las siguientes soluciones:

* **Diseño y Normalización:** Creación de un modelo Entidad-Relación robusto con integridad referencial (PK/FK) para entidades como Jugadores, Equipos y Torneos.
* **Optimización de Consultas:** Implementación de Índices (Clustered y Non-Clustered) que redujeron significativamente los tiempos de ejecución en reportes de desempeño.
* **Objetos de Base de Datos:** Desarrollo de Vistas para simplificar consultas complejas y Procedimientos Almacenados para automatizar tareas repetitivas.
* **Análisis de Rendimiento:** Uso de planes de ejecución para identificar cuellos de botella y mejorar la eficiencia de los JOINS y filtros.

---

## 🛠️ Herramientas Utilizadas
* **Motores de DB:** MySQL / SQL Server.
* **Lenguaje:** SQL Avanzado (DML, DDL, TCL).
* **Modelado:** Herramientas de diagramación E-R.

---

## 📈 Resultados Técnicos
* **Escalabilidad:** Estructura preparada para manejar grandes volúmenes de datos de torneos y estadísticas de jugadores.
* **Eficiencia:** Reducción en la latencia de consultas críticas mediante el uso estratégico de índices y normalización.
